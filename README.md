# 酷安探帖（dsh-coolapk-dive）

在 DeepSeek Harness 里搜酷安、读帖子正文，配图直接存到本地。

装好之后不用打开任何界面——直接跟 AI 说话就行，比如：

> 帮我搜一下酷安上大家怎么评价华为 FreeBuds Pro 5
>
> 酷安上最近有什么人在聊澎湃OS4？挑几条有意思的读给我听
>
> 这个帖子讲的什么：https://www.coolapk.com/feed/74732435

## 能做什么

| 能力 | 说明 |
| --- | --- |
| **搜帖子** | 按关键词搜动态，返回标题、作者、时间、机型、点赞/回复数、正文摘要和动态 id。每页 7–10 条，可以一直往后翻，翻到几年前的帖子也没问题。 |
| **读全文** | 拿动态 id（或者直接贴 `/feed/<id>` 链接）读完整正文。搜索结果里的正文是截断的，读全文才是完整版。 |
| **存配图** | 帖子里的图会自动下载到本地，AI 拿到的是本地文件路径，可以直接打开看。 |

搜出来之后 AI 会把 id 告诉你，想读哪条说一声就行；也可以自己把帖子链接丢过去。

## 读一条帖子能看到什么

- 完整正文（表情、话题标签都在，长文不会被截断）
- 作者、发布时间、机型、IP 归属地
- 点赞数、回复数、收藏数
- 全部配图（默认最多下 6 张，存到本地并给出路径）
- 热门评论（如果有的话）

## 设置页

设置 → 「酷安探帖」，可以调：

- 每次搜几条、正文摘要多少字
- 要不要下载配图、单帖最多下几张
- 要不要带热门评论
- 请求超时、两次请求之间的最小间隔
- 内存缓存存多少条、多久过期

页面上还有个「自检一下」按钮：真打一次酷安接口，把 token 生成耗时、网络延迟、命中条数报出来。工具突然不好使的时候先点它，能立刻分清是网络问题还是接口变了。

## 几个说明

**只读，不碰你的账号。** 不登录、不点赞、不回帖、不收藏，也不需要你填任何账号信息。唯一的写盘动作是保存帖子配图。

**看不到完整评论区。** 酷安的评论列表接口对外封闭，任何方式请求都返回「评论接口异常，请尝试升级到新版酷安」。所以读帖时只能带出那一两条「热门评论」，回复数是真的，但点不进完整楼层——这是接口层面的限制。

**配图存哪。** `$DSH_HOME/coolapk-dive/images/<动态id>/`，按帖子分文件夹放，方便事后翻。

**配置存哪。** `$DSH_HOME/coolapk-dive/config.json`（0600）。缓存只放内存，Harness 退出就清空，不会越攒越多。

**可能会失效。** 插件是直接对接酷安手机端接口的，靠自算签名绕开登录。哪天酷安改了算法，搜索和读帖就会一起失灵，届时需要更新插件版本。
